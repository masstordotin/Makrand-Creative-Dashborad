Top posts by saves

Team members

Members appear in the post editor's Owner dropdown so every post has a name on it. Removing someone keeps their name on existing posts.

SKUs

New SKUs appear instantly in the post editor, idea editor, filters, and copy-prompt schemas. Also add the SKU's origin and proof points to the Content Engine Kit in each team member's AI workspace — otherwise the AI won't know what to say about it.

Google Sheets sync

The Sheet is the team's source of truth. Start of session: Pull. End of session: Push. Push replaces the Sheet with this browser's data — pull first if others have been working.

How the AI workflow runs

1. Each team member has their own AI workspace (Claude, ChatGPT, or Gemini) set up with the Makrand Content Engine Kit + brand PDFs.

2. In the dashboard, click Copy week prompt / Copy ideas prompt / Copy script prompt and paste it into your AI chat.

3. Iterate there until the content is right. Ask for the final JSON block.

4. Back here, click Import from AI, paste, preview, confirm. Import only ever adds — it never deletes or overwrites existing work.

5. Friday ritual: open each Live post, fill saves / shares / clicks / orders, then Push.
